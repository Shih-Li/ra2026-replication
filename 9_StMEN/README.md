# Paper 10 Replication

## Selecting the Most Effective Nudge: Evidence From a Large-Scale Experiment on Immunization

### Replication status

**Successful with minor stochastic and cosmetic differences.**

This replication reorganizes the authors' Haryana empirical workflow into a clean project structure with source, processed, and intermediate data separated from final figures and tables. The methodological simulation exercises from the original replication package are outside the scope of this replication.

## Scope

This replication covers the Haryana empirical analysis implemented in:

- `0_create_costs_fullsample.R`
- `01_uninteracted_analysis.R`
- `02_main_analysis.R`
- `03_robustness_regularization_path.R`
- `04_saturated_OLS.R`
- `05_bootstrap_main.R`
- `05B_bootstrap_plot.R`
- `06_descriptive_statistics.R`
- `07_evaluating_substitution.R`

The separate methodological simulation exercises under the original `Code/Simulation/` directory are not included.

## Replication results

The deterministic empirical outputs reproduce the original package extremely closely.

The substitution regression tables reproduce all reported coefficients, standard errors, significance levels, control means, and sample sizes. The descriptive statistics reproduce all reported values. The available winner's-curse-adjusted cost-effectiveness result is identical to the original. The uninteracted treatment-effect figures, saturated OLS results, policy-profile plots, and heatmaps reproduce the original estimates, confidence intervals, pooling/pruning classifications, and significance markers.

Minor non-substantive differences include regenerated LaTeX timestamps, platform-specific line endings, legend ordering, and some additional figures generated by the cleaned workflow.

## Bootstrap differences

The bootstrap analysis is stochastic and does not reproduce the exact original bootstrap realization.

For the measles outcome:

- Best-policy selection accuracy is unchanged at **0.77**.
- The same substantive result is obtained.
- The bootstrap support-category colors differ because the cleaned plotting code assigns colors dynamically.

For the shots-per-dollar outcome:

- Best-policy selection accuracy is **0.955** in the replication versus **0.96** in the original.
- The selected best policy is unchanged.
- The replication realizes one additional bootstrap-support category.
- The winning policy's x-axis label is not red-highlighted in the cleaned plot.
- The support-category color palette differs from the original.

These differences do not change the substantive empirical conclusion.

## Additional and unchecked outputs

The cleaned workflow generates two outputs that did not have direct counterparts in the comparison set:

- `Heatmap_noSeed_Seed_shot_Measles1.pdf`
- `postLASSO-costeffectiveness_COEF.png`

The original package also contains `shot_Measles1_best_policy_WC_adjusted.txt`. This file was not part of the validation comparison set used for the final review and should therefore be treated as **not checked**, rather than as a failed replication.

## Overall conclusion

The empirical findings are successfully replicated.

All deterministic results checked against the original package match in substantive numerical content. The remaining differences are concentrated in the stochastic bootstrap exercise and in non-substantive plotting or formatting details.

Accordingly, this replication is classified as:

**Replicated with minor differences.**
